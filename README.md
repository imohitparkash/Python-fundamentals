# 🐍 Python Fundamentals

A structured collection of Python fundamentals practice and revision exercises based on the Code With Mosh Python course.

This repository contains small programs and exercises covering Python's core syntax, control flow, and fundamental programming concepts.

## 📚 Topics Covered

The repository covers fundamental Python concepts including:

- Variables and data types
- Input and output
- Arithmetic and comparison operators
- Conditional statements
- `while` loops
- `for` loops
- Control flow
- Basic problem-solving exercises
- Python syntax and programming fundamentals

More topics will be added as the course progresses.

## 📁 Repository Structure

```
Python-fundamentals/
└── src/
    └── Code_With_Mosh/
        └── Basics/
            ├── ...
            └── ...
```

The `Basics` directory contains the Python programs and exercises organized around the topics covered in the course.

## 🎯 Purpose

The purpose of this repository is to:

- Practice Python fundamentals through code
- Reinforce core programming concepts
- Keep track of progress through the course
- Maintain a practical reference for Python syntax and concepts
- Build consistency through regular coding practice

This is intentionally focused on fundamentals and practical repetition rather than advanced Python development.

## ▶️ Running the Programs

Make sure Python 3 is installed on your system.

Clone the repository:

```bash
git clone https://github.com/imohitparkash/Python-fundamentals.git
```

Navigate into the repository:

```bash
cd Python-fundamentals
```

Individual Python files can then be executed with:

```bash
python filename.py
```
